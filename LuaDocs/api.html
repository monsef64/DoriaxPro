Lua API Reference

Every binding is exposed via Luabridge3 from engine/core/script/binding/*.cpp. Search by class, method, property or enum. All signatures work on both Windows x64 (MSVC) and Linux x64 (GCC).

⬡ Engine static Core

singleton

Global engine control — canvas, scenes, lifecycle, jobs. Accessible from anywhere: Engine.canvasWidth.

Properties

Engine.sceneScene*get · set

Main scene. Setter is thread-safe and triggers onViewLoaded when the view is ready.

canvasWidth / canvasHeightintget

Drawable size in pixels (after scaling). Prefer viewRect for letterboxed area.

scalingModeScalingget · set

Scaling.FITWIDTH | FITHEIGHT | LETTERBOX | CROP | STRETCH | NATIVE. Controls how canvas maps to window.

deltatime / frameratefloatget

Frame delta (s) and smoothed FPS. Use deltatime for frame-rate independent motion.

asyncLoadingboolget · set

Offloads texture/model builds to ThreadPoolManager. Loading screen can poll ResourceProgress.

Methods

SignatureNotes
Engine:setCanvasSize(w:int, h:int)Triggers onCanvasChanged and resizes framebuffers.
Engine:addSceneLayer(scene)Stack a scene — useful for persistent HUD.
Engine:pauseGameEvents(bool)Pauses all onUpdate/onFixedUpdate except explicit layers.
Engine:startAsyncThread() / commitThreadQueue()Advanced: run work off-main-thread safely.

Events

PropertySignature
onUpdatefunction() — per frame
onFixedUpdatefunction() — physics tick
onViewLoadedfunction() — GL/Metal/Vulkan ready
onKeyDown / onKeyUp / onCharInputfunction(key, scancode) etc.
lua — engine basics
Engine.scalingMode = Scaling.LETTERBOX
Engine.onViewLoaded = function()
  Log:info("canvas %dx%d", Engine.canvasWidth, Engine.canvasHeight)
end
Engine.onUpdate = function()
  if Engine.framerate < 30 then Log:warn("low FPS") end
end

◬ Scene · SceneManager · BundleManager Core

Scene flow

Scene

A Scene owns an EntityRegistry and runs its own systems (render, physics…). Create one or load a saved editor scene.

APIDescription
Scene.new()Create empty scene.
scene:findObject(name:string)Find first Object by name.
scene:getEntityCount()Live entity count.

SceneManager (static)

SignatureNotes
SceneManager.loadScene(id:number|string)Replace main scene. Async when asyncLoading is on.
SceneManager.addChildScene(id)Overlay a scene (HUD, pause). Removed via removeChildScene.
SceneManager.preloadScene(id) + getPreloadProgress(id)Warm up async load. Use holdLoading / releaseLoading for cinematic bars.
SceneManager.sceneCount / currentSceneName / loadingProgressStatus properties.

BundleManager (static)

Reusable entity packs in a scene — shared or local.

Signature
BundleManager.createBundle(nameOrId, scene, entityOrName)
BundleManager.destroyBundle(id) / getBundleNames()
lua
SceneManager.registerScene(1, "Level1", function()
  local scene = Scene.new()
  -- build…
  Engine:setScene(scene)
end)
SceneManager.loadScene("Level1")

◈ EntityHandle · EntityRegistry ECS

Entity Pool

Doriax ECS is archetype-based. EntityHandle is the safe, Lua-friendly reference (never dangling).

◼ Object World ECS

Transform hierarchy

Base of every scene entity. Holds Transform and is the parent of Camera, Mesh, Light, etc.

MemberType / signature
position / rotation / scaleVector3 · Quaternion · Vector3 — world via getWorldPosition/Rotation/Scale()
visible / visibleInHierarchybool — culling respects hierarchy
billboard / cylindricalBillboard / fakeBillboardbool — face camera (true 2D or cylindrical)
localMatrix / modelMatrix / normalMatrixMatrix4 / Matrix3 — local vs composed world
addChild(obj) / removeParent() / moveToTop()Hierarchy — order affects 2D draw & update
getBody2D / removeBody2D / getBody3D / getRay()Physics & picking shortcuts
lua — hierarchy
local parent = Object.new(scene)
local child  = Mesh.new(scene)
parent:addChild(child)
child.position = Vector3.new(0, 1, 0)
print(parent:getWorldPosition()) -- includes parents
child:setBillboard(true, true, false)

⚙ Body2D · Body3D · Joints & Shapes Physics

Box2D (2D) and Jolt (3D) behind one API. Bodies are components attached to an Object.

ClassAPI
Body2D : ObjectbodyType (BodyType.STATIC/DYNAMIC/KINEMATIC), linearVelocity (Vector2) angularVelocity, applyForce / applyImpulse / setShape(Shape2DType, …), events: onBeginContact / onEndContact via FunctionSubscribe
Body3D : ObjectmotionQuality (Body3DMotionQuality), mass, addShape(Shape3DType, …) collideShapeResult, Jolt events
Joint2D / Joint3DJoint2DType.REVOLUTE/PRISMATIC/DISTANCE… — connectedBody, enableMotor, motorSpeed
Contact2D / Manifold2D / CollideShapeResult3DCollision callbacks payloads — use in onBeginContact
lua — dynamic body
local ball = Body2D.new(scene)
ball.bodyType = BodyType.DYNAMIC
ball:setShape(Shape2DType.CIRCLE, 0.5)
ball.linearVelocity = Vector2.new(0, 4)
ball.onBeginContact:add("onHit", function(a, b) Log:info("hit") end)

▶ Action · Ease · Animation Gameplay

Tween system: compose Action → target property → play on any Object.

ClassAPI
ActionAction.new(scene, target), start() pause() stop() restart(), speed, weight, target
TimedAction : Actionduration, loop, pingPong, setFunctionType(EaseType)
AlphaAction / ColorAction / PositionAction / RotationAction / ScaleActionsetAction(ease, from, to) setSpinAction(speedAxis)
Particles / SpriteAnimation / AnimationAnimation: addActionFrame(Action, startTime, duration) fadeIn/fadeOut()
EaseEase.new(EaseType), .type, setFunction(luaFunction), static helpers: Ease.linear, easeInQuad, easeOutBounce, … (32 curves)
lua — ease & tween
local move = PositionAction.new(scene, myObj)
move:setAction(Ease.easeOutBack(), Vector3.new(0,0,0), Vector3.new(4,0,0))
move.duration = 0.5
move:start()

-- custom curve
local e = Ease.new(EaseType.CUSTOM)
e:setFunction(function(t) return t*t*(3-2*t) end)
